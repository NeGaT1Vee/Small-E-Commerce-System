Slide 02 / 22 • Objectives

Project Vision & Core Objectives

Why engineer a custom commerce backend?

  • Precise Domain Representation: Expressing store rules, stock validation, and customer carts naturally through strong typing and OOP abstractions.
  • Decoupled Clean Architecture: Keeping logic layers independent so models, persistence, and GUI can evolve without breaking adjacent systems.
  • Zero-Dependency Storage: Custom serialization mechanisms guaranteeing reliable state persistence to local JSON data files.
Slide 03 / 22 • OOP Pillars

Applying Core OOP Principles

Architectural pillars guiding code quality

Encapsulation

Internal attributes are shielded via double-underscore private naming (`__attributes`) paired with Python properties (`@property`) and validation setters.

Abstraction

Abstract Base Classes (e.g., `Payment`) define rigid execution contracts for all payment implementations without exposing internal mechanics.

Composition

Complex domain entities build upon simpler ones—Customers encapsulate individual Carts, and Orders maintain lists of OrderItems.

Slide 08 / 22 • Product Model

The `Product` Model

Central inventory unit & stock guardrails

class Product:
    def __init__(self, product_id: str, name: str, price: float, stock: int, category: Category):
        self._product_id = product_id
        self._name = name
        self._price = price
        self._stock = stock
        self._category = category

    def reduce_stock(self, quantity: int):
        if quantity > self._stock:
            raise ValueError("Insufficient stock available.")
        self._stock -= quantity

def add_product(self, product: Product):
    if product.product_id in [p.product_id for p in self.__product]:
        raise ValueError(f"Product ID '{product.product_id}' already exists.")
    self.__product.append(product)
    self.save_all()

def get_product(self, search_term: str) -> Product:
    for product in self.__product:
        if product.product_id == search_term or product.name.lower() == search_term.lower():
            return product
    raise ValueError(f"Product '{search_term}' not found.")

Slide 20 / 22 • Checkout Method

Executing the `checkout` Method

Atomic execution & state commitment

def checkout(self, customer_id: str, payment_method: Payment) -> Order:
    customer = self.get_customer(customer_id)
    order = Order.from_cart(customer.cart)
    
    payment_method.process(order.total())
    order.mark_paid()
    
    # Deduct stock & clear user cart
    for item in customer.cart.items:
        item.product.reduce_stock(item.quantity)
    customer.cart.clear()
    
    self.save_all()
    return order
